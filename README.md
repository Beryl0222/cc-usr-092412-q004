# 健康规划指标口径库

面向慢病规划评估的**指标口径谱系、跨边界守恒换算、候选序列计算与发布冻结**领域服务。
解决“五年曲线在行政区划调整、分母定义修订、迟到补报并发时究竟是否可比”的问题。

## 领域机制

### 1. 口径谱系（不可变版本）

每个指标的每一版口径保存：公式标识、分子来源、分母来源与**分母定义版本**、适用人群、
适用地域边界版本、质量规则集合、与上一版的前驱指针和变更说明。修订只产生新版本，
旧版本永不原地改写；评估时按 `effective_from` 取时点有效版本。

- 地域边界同样版本化（成员区划清单 + 合并/拆分变更说明）。
- 跨边界换算方案必须**有依据**（区划文件、普查等），且对每个来源区划的流出权重之和
  满足 `0 < Σweight ≤ 1`：权重缺口即“无法归属到任何目标区划”的份额。
- 换算执行用 Hamilton 最大余数法在“目标桶 + 残差桶”间分配整数计数，
  **严格守恒：Σ分摊 + 残差 ≡ 输入总量**，残差按来源区划登记披露，绝不静默丢弃。
  残差率超过口径容忍线（默认 5%）时质量规则不放行。

### 2. 上报、冲突与质量规则

- 数据源登记**到期时间**与**复核期限（天）**，均由可控时钟判定；到期须续期。
- 上报批次不可变；更正以“迟到补报批次 + `supersedes_batch_id` 更正链”表达，
  批次带内容指纹与复核截止时间。
- 同一指标同一年出现互无更正关系的多个来源时，自动进入**待决冲突队列**，
  该年点位留空；冲突须记录依据与胜出批次裁决后重算。
- 质量规则（分母非零、残差率、来源未到期、无未决冲突、未超复核期限）只自动评估留证，
  是否接受例外由统计负责人决定。

### 3. 自动计算只产出候选序列 + 故障恢复

- 计算作业按“指标 × 年”拆成确定性步骤，每步落 `JOB_STEP_COMPLETED`；
  崩溃恢复后**跳过已完成步骤继续未完成计算**，事件 `event_id` 幂等保证
  **不重复产出候选、不重复发布**。
- 候选序列带完整血缘：口径版本、来源/目标边界、换算方案、残差、输入批次、
  输入指纹（含期范围）。自动计算结果一律是“候选”，未经双签不得发布。

### 4. 双重批准与冻结发布

闸门顺序缺一不可：

```
自动候选 → 统计负责人 QUALITY_CONFIRMED → 业务负责人 USE_APPROVED（指定规划评审）
         → RELEASE_PROPOSED → RELEASE_FROZEN（快照深拷贝 + 哈希，幂等）
```

- 冻结数据包面向某次规划评审；批准的评审用途必须与冻结评审一致。
- 冻结快照永不改写、哈希固定；重复冻结返回同一事件。
- **迟到补报**：未发布序列可以重算并取代旧候选（旧候选标记 `superseded_by`）；
  已冻结序列不能重算改写，只能在统计负责人确认新结果后向冻结包
  **追加 `RELEASE_REVISED` 修订**（数值差异 + 是否影响评审结论），
  已引用该包的报告只收到 `REPORT_REVISION_APPENDED` 修订影响，报告原文不改写。

### 5. 血缘追溯与可比性判定（只读）

- `explainValue(seriesId, period)`：任一数值采用的口径版本、公式、分母定义、
  来源/目标边界、换算方案及依据、分子分母与残差、输入批次（来源、有效期、指纹）、
  质量规则证据、提出/质量确认/用途批准链、所在冻结包。
- `compareSeries(a, b)`：逐条给出可比/不可比理由——口径语义断裂（分母定义修订等）、
  是否经有依据的守恒换算及残差率、边界版本差异、缺换算断点、未决冲突、被取代提示。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `src/domain.ts` | 领域类型词汇（口径、边界、换算、批次、候选、冻结包） |
| `src/vocabulary.js` | 事件/聚合类型枚举（与 domain.ts 同步） |
| `src/clock.js` | 可控时钟：到期、复核期限由测试显式推进 |
| `src/event-store.js` | 仅追加事件存储：版本递增、event_id 幂等、递归冻结、快照恢复、指纹 |
| `src/formulas.js` | 白名单公式（不接受任意表达式） |
| `src/quality.js` | 质量规则集与证据 |
| `src/lineage.js` | 口径/边界版本谱系与守恒换算 |
| `src/ingestion.js` | 数据源、批次上报、冲突待决队列 |
| `src/computation.js` | 计算作业（步骤恢复）、候选序列、迟到重算 |
| `src/publication.js` | 双签闸门、冻结发布、报告引用、只追加修订 |
| `src/provenance.js` | 血缘追溯与可比性判定 |
| `src/app.js` | 装配门面与整体快照/故障恢复 |
| `contracts/domain.schema.json` | 领域事件契约 |

## 领域边界

事件一旦被接收，其标识、发生时间和版本不应被原地改写；业务更正一律产生后继事件
（新口径版本、更正链批次、候选取代、发布修订）。涉及个人、机构或商业敏感信息时，
调用方只读取完成职责所必需的字段。
