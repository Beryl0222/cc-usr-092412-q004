# 健康规划指标口径库

面向规划评估的指标平台：为每个指标保存**口径谱系**，用**有依据的边界换算**衔接行政区划调整，自动计算只产出**候选序列**，经统计负责人质量确认、业务负责人用途批准后，才冻结成面向某次规划评审的**发布包**。

## 机制总览

| 机制 | 实现 | 说明 |
| --- | --- | --- |
| 口径谱系 | `src/definitions.js` | 每个版本完整保存公式、分子分母来源、适用人群、地域边界、质量规则；批准后不可改写，修订只能登记后继版本，并强制声明与上一版本的可比关系 |
| 边界换算 | `src/boundaries.js` | 合并/拆分方案必须附依据；分摊权重守恒（合计 ≤ 1），未分摊残差必须说明去向；冲突方案进入待决队列，裁决前不生效 |
| 候选计算 | `src/compute.js` | 自动计算只产出候选条目；按期间逐个落事件，故障后重放日志即可断点续算，不重复计算 |
| 发布冻结 | `src/releases.js` | 质量确认 + 用途批准双门禁；复核后候选有变化必须重新复核；同一 release_id 幂等；冻结快照永不改写 |
| 迟到补报 | `src/platform.js` | 未发布序列自动重算；已冻结发布包只追加修订影响（RELEASE_REVISED） |
| 可控制时钟 | `src/clock.js` | 数据源到期与复核期限由时钟推进，扫描结果落事件且幂等 |
| 谱系查询 | `src/lineage.js` | 任意数值可追出口径版本、边界与换算、输入批次、批准链；两期间可比性给出"可比 / 可比但有保留 / 不可比"及原因 |

## 事件与状态

- 事件日志（`src/store.js`）追加式、按 `event_id` 幂等；事件一旦被接收，其标识、发生时间和版本不得原地改写，业务更正只产生后继事件。
- 全部读模型（`src/state.js`）都是日志的投影：用同一日志重建平台即完成故障恢复。
- 事件类型与聚合类型以 `contracts/domain.schema.json` 为准；`src/validator.js` 校验信封，`tests/contract.test.js` 用真实场景回归契约枚举。

## 目录

- `contracts/domain.schema.json`：领域事件的基础字段、聚合类型和事件名称。
- `data/sample.json`、`data/sample-release.json`：可用于联调的中文样例记录。
- `src/`：领域服务（上文各模块）与基础信封校验。
- `tests/`：按机制划分的测试与五年慢病场景演练。

## 测试与构建

测试命令：

```bash

```

编译或构建命令：

```bash
npm run build
```

这些命令可在单个 Linux 应用容器内执行，不需要另行启动外部服务。
